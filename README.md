**Recetario** is a static and responsive recipe book website built with **HTML5** and **CSS3**, designed to showcase multiple dishes in a clean, organized format. It simulates a food blog or cooking catalog, with a focus on layout, readability, and visual hierarchy.

## 🌐 Live Preview

- 🔗 **Live Website**: [https://proyectarecetario.netlify.app](https://proyectarecetario.netlify.app)  
- 📁 **GitHub Repository**: [https://github.com/Aleji0309/proyectaRecetario](https://github.com/Aleji0309/proyectaRecetario)

## 🛠️ Technologies Used

- **HTML5** – Semantic structure for recipes and sections  
- **CSS3** – Custom styles, layout, and responsive design  
- **Netlify** – Deployment and hosting

## 📋 Project Description

This website displays a selection of recipes in a card-based layout. Each recipe contains:

- A title and image  
- A short description  
- A list of ingredients  
- Basic preparation steps

No JavaScript was used — the focus is entirely on structure, accessibility, and visual styling.

## 📌 Key Features

- Grid-based recipe layout  
- Mobile-first responsive design  
- Readable and organized typography  
- Consistent visual styling across all sections  
- Fast and lightweight static page

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaRecetario.git
````

2. Navigate to the folder:

```bash
cd proyectaRecetario
```

3. Open the `index.html` file in your browser.

> This is a static project — no installation or dependencies needed.
